# Homebrew ClipMaker

Private staging tap for installing and updating ClipMaker on macOS.

This repository contains packaging metadata only. The ClipMaker application and
its shared frontend remain in the main private repository.

The release process will add `Formula/clipmaker.rb` after a downloadable
ClipMaker release archive exists. Until then, this tap is intentionally not
installable.

Planned installation command:

```sh
brew tap B03GHB4L1/clipmaker
brew install clipmaker
```
